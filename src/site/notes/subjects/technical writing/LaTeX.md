#technicalWritng 
## What shall be covered throughout the semester:

1. **The Bases of LaTeX**:
   - **Installation and Editors**: Setting up and navigating LaTeX environments like **TeXstudio** and **Overleaf**.
   - **Document Construction**: Writing a basic document skeleton using structural commands like `\documentclass`, `\begin{document}`, and `\end{document}`.
   - **Text Formatting**: Learning text formatting (bold, italics) and creating standard lists.

2. **Structuring Long Documents**:
   - **Hierarchy**: Creating structured divisions using sections and subsections.
   - **Automation**: Generating a table of contents automatically.
   - **Cross-Referencing**: Linking text, figures, and equations dynamically using `\label` and `\ref`.

3. **Tables (Tableaux)**:
   - **The `tabular` Environment**: Designing columns and aligning cell content.
   - **Captions**: Wrapping tables in floating environments with titles/descriptions using `caption`.

4. **Images**:
   - **Insertion**: Importing image files with `\includegraphics`.
   - **Positioning**: Utilizing the floating `figure` environment to control how and where images are positioned on the page.

5. **Mathematical Equations**:
   - **Display Modes**: Typesetting equations in either inline text or separate block formats.
   - **Math Notation**: Implementing numbered equations, fractions, indices, exponents, and matrices.

6. **Bibliography with BibTeX**:
   - **Reference Management**: Creating and organizing citations inside a `.bib` database file.
   - **Citations**: Referencing specific works in your text using `\cite`.
   - **Bibliography Generation**: Compiling and displaying your reference list with `\bibliography`.

---

## Practical Work & Evaluation

- **Exercise 5**: Build a **2‑page mini‑document** putting all these skills together by including an introduction, a formatted table, a figure, a mathematical equation, and a working bibliography.
- **The LaTeX Project**:
  - **mini scientific report** written entirely in LaTeX.
